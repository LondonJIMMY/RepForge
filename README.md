# RepForge

RepForge is a phone-first, installable workout planner and training log. It runs entirely in the browser, works offline after the first visit, and saves data locally on the device.

## Publish free with GitHub Pages

1. Create an empty GitHub repository.
2. Upload every file and folder from this project to the repository's `main` branch.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Open the deployment URL shown by GitHub after the workflow finishes.
5. On iPhone use **Share → Add to Home Screen**. On Android use the browser menu and choose **Install app** or **Add to Home screen**.

## Important data note

There is no account or paid server. Workouts stay in this browser on this device. Use **Settings → Export backup** regularly, especially before clearing browser data or changing phones.

## Features

- Searchable built-in exercise library plus unlimited custom exercises
- First-launch questionnaire for goals, measurements, experience, schedule, and equipment
- Editable personal profile with starting, current, and goal-weight tracking
- Goal-based workout recommendations and quick weight check-ins
- Crunch Fitness equipment profile with dedicated machine, strength, cardio, and HIITZone workouts
- Built-in routines and custom routine builder
- Active workout logging for weight, reps, time, distance, RPE and notes
- Automatic rest timer, elapsed timer, set editing and workout recovery
- History, total volume, personal records and exercise trends
- Pound/kilogram preference, JSON backup/import, CSV export
- Offline-ready progressive web app

General fitness information only; this app is not medical advice.
